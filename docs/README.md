# Le labo jazz — Body and Soul

Ouvrir `index.html` dans un navigateur. Le dossier est autonome : CSS, JavaScript et images sont inclus. Les outils audio utilisent Web Audio et démarrent après un clic. Les liens de sources nécessitent Internet.

## Parcours

1. Bases de l’harmonie
2. Body and Soul : cadences, forme et pont
3. Rythme : triolets de noires et liaisons d’après la feuille fournie
4. Gammes blues majeure et mineure dans douze tonalités
5. Cycle des quintes, notes et cadences
6. Projet, exercices, QCM et répertoire

Les pages proposent lecture continue, mode présentation et impression / PDF avec corrections ouvertes. La progression est enregistrée localement dans le navigateur quand son stockage est disponible.

## Conventions

La photo est notée en Mi♭. La tonalité habituelle est Ré♭ concert. L’identification de la photo comme partie de ténor Si♭ attend confirmation. Les outils de gammes et du cycle utilisent des noms en sons réels / théoriques, sans transposition automatique.
